# diutalia

diutalia is a fork of an older version of [noctalia](https://github.com/noctalia-dev/noctalia) during the 4.x release.
Noctalia moved past the v4 release and now looks and behaves completly different.
Aesthetics are subjective, but they are not to my likly and look like to much vibe coding without any real vision.

This is a fork that bundles all v4 plugins and themes and does no longer communicate with noctalia servers.
It is a self-contained project with fixes for Hyprland+Wayland and features that noctalia was missing.
